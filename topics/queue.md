# Topic queue

One **client-demo website** idea per line. The daily agent takes the **first unchecked** item, builds it, then checks it off.

Format:

```
- [ ] short-slug | Human brand title | One-sentence niche + who would hire you after seeing it
```

## Rules for writing topics

- Each item is a believable business or institution demo (shop, school, mosque, clinic, firm, etc.) — **not** a utility tool.
- Slugs must be unique, lowercase, hyphenated, brand-like, and safe as a GitHub repo name.
- Aim for mix over time: ~40% local commerce, ~40% institutions, ~20% professional services.
- Do not repeat the same category two days in a row.
- Keep unchecked items above done/cancelled ones when editing.
