# Topic queue

One useful website idea per line. The daily agent takes the **first unchecked** item, builds it, then checks it off.

Format:

```
- [ ] short-slug | Human title | One-sentence usefulness + who it is for
```

Rules for you when writing topics:
- Each idea must solve a real, specific problem (calculator, converter, checklist, planner, lookup, generator with real utility — not a landing page for a fake product).
- Slugs must be unique, lowercase, hyphenated, and safe as a GitHub repo name.
- Prefer niche tools over generic SaaS marketing sites.
- Do not repeat the same category two days in a row if you can help it.
